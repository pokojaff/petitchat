Sustainability & Digital Responsibility

Last updated: October 2026

At Petit chat, s.r.o., digital products should stay useful without wasting energy, data, or hardware. This statement covers how we build and run our own products. It is not a carbon-footprint certificate, and it does not replace a client's own environmental policy when we deliver software for them.

1. Infrastructure

The energy cost of software is mostly the energy cost of the computers that run it. We host production workloads in the European Union and prefer providers that publish how their regions use power and how efficient their data centres are. Capacity is sized to the load a product actually has, so we are not paying — or powering — idle machines we do not need.

2. Efficient Software

Smaller, simpler processing uses less electricity on the server and on the device in someone's hand:

  • Lean processing: We keep background work and queries to what the feature needs, instead of recomputing or transferring the same data over and over.
  • Data minimisation: Products store and request only the fields they use. That includes data harvested from sensors, wearable devices, and cloud services a user chooses to connect.
  • Device impact: Mobile apps avoid unnecessary background wake-ups, so the phone or watch is not kept busy when the user is not using the feature.
3. How We Operate

We are a remote-first team. Day-to-day work, contracts, and internal documentation are digital, which keeps commuting and paper out of the normal run of the company.

4. Hardware

We buy hardware we expect to keep in use, repair it when that is reasonable, and send equipment we retire to e-waste recycling rather than discarding it as mixed waste.

5. Continuous Improvement

We revisit hosting, data flows, and how our apps behave on devices as products change. The aim is a smaller footprint for the same service, not a one-time claim.

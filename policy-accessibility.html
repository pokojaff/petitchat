Accessibility Statement

Last updated: October 2026

Petit chat, s.r.o. wants people with disabilities to be able to use our website and the products we publish. That includes web applications and native mobile apps. This statement describes the standard we design toward and how to tell us when something blocks you. It is a commitment and a feedback channel, not a claim that every screen has been formally certified.

1. Standard We Design Toward

For websites and web apps we use the Web Content Accessibility Guidelines (WCAG) 2.2 Level AA as the target. Those guidelines cover visual, auditory, physical, speech, cognitive, language, learning, and neurological disabilities. Native apps follow the accessibility APIs of the platform they ship on, including VoiceOver, Dynamic Type, and keyboard or switch access on Apple platforms, and TalkBack where we ship on Android.

2. What We Pay Attention To
  • Structure: Pages and screens use real headings, labels, and control names so assistive technologies can follow them.
  • Keyboard and switch access: Primary tasks on the web can be reached without a pointer, in an order that matches the page.
  • Text and contrast: Text can scale with the system or browser setting, and interface colours are chosen so text stays readable.
  • Plain language: Labels and instructions stay short and concrete, especially where a product shows health or activity information.
3. Assistive Technologies

We design for current versions of VoiceOver, TalkBack where the product is on Android, browser zoom, and the system text-size settings. An unusual combination of an old browser and an assistive tool may still fail; if it does, write to us and name the product, the operating system, and the tool you use.

4. Known Limits

We test with automated checks and by using the products ourselves, including with platform assistive technologies. We have not commissioned a full external audit of every screen, so some barriers will remain until they are found and fixed. Third-party content that a product only displays, such as a connected provider's own screens, is outside what we can make accessible.

5. Feedback

If a page or a feature blocks you, email support@petitchat.cz. Say which product, what you were trying to do, and what happened. We aim to reply within 5 business days and to fix confirmed barriers in the product they belong to.

6. Technologies

Web accessibility depends on HTML, WAI-ARIA, CSS, and JavaScript working with your browser and assistive technology. Native apps depend on the platform UI frameworks and the accessibility settings of the device.
